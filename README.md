# Tandem

Tandem centralizes planning, execution, and tracking of software development work for teams of Product Owners, Developers, and Team Leads. See [docs/prd.md](docs/prd.md) for the full product context and [docs/modelo-datos.md](docs/modelo-datos.md) for the data model.

## Repository layout

- [docs/](docs/) — product and architecture documentation (PRD, data model, backend and frontend architecture).
- [backend/](backend/) — NestJS/TypeScript API. See [docs/backend.md](docs/backend.md) for stack and architecture.
- [frontend/](frontend/) — SwiftUI macOS app. See [docs/frontend.md](docs/frontend.md) for stack and architecture.
- [openspec/](openspec/) — OpenSpec change proposals and specs driving development of this repository.
